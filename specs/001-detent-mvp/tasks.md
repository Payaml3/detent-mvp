## Dependencies

Slices run in order. Inside a slice, follow each story's `deps` in `backlog/stories.yaml`; the build fails if a story depends on a later slice. P1 to P4 (portal) need S1 for the API shape; WEB-01 and WEB-02 can start at any time (backlog/milestones.md, Parallel work).

## Implementation strategy

1. Finish each slice to its exit check; each one is demonstrable on its own.
2. S1 to S5 together are the demo's first six minutes; S6 to S9 complete the prototype.
3. Per story: Superpowers test-driven development (red, green, refactor), then verification before completion.
