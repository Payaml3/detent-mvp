---
title: "Try it from the reference"
description: "Send real sandbox requests from the API reference pages with your sandbox key."
---

Every page in the [API reference](/api-reference) has a **Try it** panel. Paste your `sk_test_...` key into the
authorization field, fill in the request and send it: it goes to the sandbox, and you see the real response.

- **No key yet?** Each page still shows example requests in eight languages and example responses. Use
  **Request sandbox access** at the top of the page to ask for a sandbox.
- **Only the sandbox.** The reference names only sandbox and local servers, and a live key (`sk_live_...`) is
  refused everywhere: nothing you send from here can move real money.
- **Requests that create something** need an `Idempotency-Key` header. Put in any new value, such as a UUID, for
  each new request.

Requests from the panel are recorded in your organisation's request log in the dashboard, like any other. Use a
key with only the scopes you need, and revoke it in the dashboard when you are done.
